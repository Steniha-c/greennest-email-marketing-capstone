# GreenNest — CAPSTONE 26

## Project Overview
GreenNest is a fictional eco-friendly lifestyle brand used to demonstrate how AI can support an ethical five-email marketing sequence.

## Project Objectives
- Create five marketing email drafts.
- Develop alternative subject lines and record subject-line testing.
- Create email header banners.
- Use Google Apps Script to automate Gmail draft creation.
- Review marketing content for honesty, privacy, consent and responsible AI use.
